Your YouTube intro, made by Claude Code. One command: a 5-second MP4 with motion graphics, music and sound effects.

Star on GitHub Install

Install

/plugin marketplace add mahmoud-emad/intro-maker
/plugin install intro-maker@intro-maker

Then, in any folder:

/intro "Code With Sam" --style neon --duration 5
