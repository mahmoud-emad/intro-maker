# Concept fuel

Ideas come from the **subject**. Ask: *what physical thing, moment, sound or ritual does this channel own?* Then make the name appear through it.

## Method

1. List 5 concrete objects/actions from the channel's world (not abstractions).
2. Pick the one with the best **motion** (something that moves, grows, falls, lights up, pours, types, bounces).
3. Ask how the name could be *made of*, *revealed by*, or *delivered by* that thing.
4. Find the sound that thing makes and put it on the hit.

## Examples of subject → idea

| Channel | Idea |
|---|---|
| Sourdough / cooking | Steam condenses into the name on a fogged window; oven-timer bell on the hit |
| Retro gaming | Fake boot sequence, loader fills, letters drop in frame-stepped, coin chime |
| Coding / terminal | Command typed, output scrolls, name is the final line; key clicks, a return-key thunk |
| Space / science | Star field parallax, a signal resolves from noise into letters; low sub swell |
| Fitness | Plates slam, name stamped by an impact with a screen shake; kick drum |
| Music production | Waveform draws, then morphs into the name; the intro audio is the beat |
| Travel | Map line draws a route and the name pops where it lands; passport stamp thud |
| True crime / mystery | Typewriter + redaction bars slide off to reveal the name; low drone, paper rustle |
| Finance | Candlesticks climb and the last candle becomes the underline; cash-register tick |
| Kids / education | Bouncy blocks assemble the name with squash-and-stretch; xylophone notes |
| Photography | Shutter iris closes, flash, name develops like a print; shutter click |
| Fashion / luxury | Fabric-like gradient sweep, thin serif, gold hairline; one soft chime |

Use these as a pattern for thinking, not a menu to pick from. Invent new ones.

## Palette logic

- Derive from the subject (warm ambers for food, cold cyans for science), then break one expectation.
- Ground + text + **one** accent. A second accent only if the concept needs it.
- Dark grounds read as "premium/tech", light grounds as "friendly/clean". Pick on purpose.

## Typography logic

- Pick personality first, then a family. Mono = tech/hacker, high-contrast serif = craft/luxury, heavy sans = energy, condensed caps = impact.
- Case, weight and tracking are design decisions. Wide tracking = calm/expensive; tight + heavy = loud.

## Motion vocabulary (choose a dialect and stay in it)

- **Smooth**: power/sine eases, blur resolves, slow pushes (calm, premium)
- **Snappy**: back/expo eases, overshoots, squash and stretch (friendly, energetic)
- **Stepped**: `steps(n)` eases, hard cuts, flicker (retro, glitchy, mechanical)
- **Physical**: gravity, impact, shake, debris (heavy, sporty)

Mixing dialects inside one intro usually looks unfocused.

## Sound vocabulary

- **Warm**: pads in a major key, soft bells (sine, long decay)
- **Digital**: square/saw arpeggios, noise bursts
- **Impact**: sub thud + noise tick, risers
- **Organic**: filtered-noise swells (wind, steam, water), clicks

Silence is a tool: a 150 ms gap before the hit makes it hit harder.

## Anti-patterns

- A generic glow + sweep that fits any channel
- Three effects fighting for attention
- Text smaller than ~6 % of the frame height, or on screen for under 1 s
- Neon everything
- Reusing your last concept with new colours
